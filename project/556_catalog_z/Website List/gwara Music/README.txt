# Static Nostalgia Music Website

Upload these files/folders directly to your hosting's `public_html` (or equivalent web root):

- index.html
- style.css
- script.js
- bg/scene-wide.png
- bg/scene-tall.png

Your website URL will automatically open `index.html`.

## Add music

Edit `script.js`, inside one of the playlist arrays.

Example:

{ id: "gm-01", title: "Your licensed track", artist: "Artist", film: "Film", year: 2005, duration: 240, videoId: "YOUR_YOUTUBE_VIDEO_ID" }

Only add YouTube videos you have the right to use, or videos uploaded by the rights holder with embedding enabled.

The YouTube player remains visible in the artwork area. No thumbnails are downloaded or re-hosted.
