About the studio

A face is prepared the same way a room is, before guests arrive.

Shalin Studio is run by Lipee Shrestha, a makeup artist working across bridal, party and editorial makeup. Every booking starts as a conversation — about the outfit, the venue light, the hours the day will actually run — before a single brush is opened.

The studio's approach stays close to the skin: long-wear bases suited to Kathmandu's weather, colour work that photographs true under both daylight and mandap lighting, and finishing that's built to last from the first ritual to the last dance.
